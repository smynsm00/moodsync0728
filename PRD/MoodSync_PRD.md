# PRD - 감성 무드 필터 및 에셋 추출 웹 서비스 (MoodSync)

> Version: v0.9 Draft

## 1. 프로젝트 개요

**MoodSync**는 디자이너를 위한 AI 기반 감성 무드 변환 및 톤앤매너 일관성
유지 플랫폼입니다.

## 2. 프로젝트 배경

기존 AI 이미지 도구는 이미지별 톤앤매너 일관성 유지, 결과 비교, 개발자
핸드오프에 한계가 있습니다.

## 3. 제품 비전

AI 이미지 생성 이후의 디자인 후반 작업(Post-Production)을 표준화합니다.

## 4. 목표

-   디자인 작업 시간 70% 절감
-   브랜드 톤앤매너 유지
-   개발자 핸드오프 자동화

## 5. 타겟 사용자

-   UI/UX 디자이너
-   브랜드 디자이너
-   마케팅 디자이너
-   프론트엔드 개발자

## 6. User Journey

1.  다중 이미지 업로드
2.  AI 무드 프리셋 선택
3.  결과 비교(Grid / Split)
4.  Tone Lock 적용
5.  Batch Sync
6.  미세 조정
7.  이미지 및 에셋 Export

## 7. 핵심 기능

  Priority   기능
  ---------- -----------------------
  P1         다중 이미지 업로드
  P1         AI 무드 프리셋
  P1         Comparison Viewer

  P1         Batch Sync
  P1         Batch Export
  P2         Color Palette 추출
  P2         CSS/JSON Token Export
